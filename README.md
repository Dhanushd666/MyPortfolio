# Dhanush P — Personal Portfolio

## Run locally
1. Extract the ZIP.
2. Open this folder in Visual Studio Code.
3. Install the Live Server extension if needed.
4. Right-click `index.html` → **Open with Live Server**.

## Easy customization
- **Text, projects, services, social links and contact details:** edit `index.html`.
- **Colours, spacing, typography and layout:** edit `style.css`. The main colour variables are at the top.
- **Theme toggle, mobile menu and certificate carousel:** edit `script.js`.
- **Your photos:** replace the files in `assets/photos/` while keeping the same filenames, or update their image paths in `index.html`.
- **Certificates:** all ten uploaded PDF files are in `assets/certificates/`. Each card has a View certificate button and an online verification link.
- **GitHub repositories:** search `https://github.com/` in `index.html` and replace each placeholder with the matching project URL.
- **Social profiles:** replace the LinkedIn, Instagram and X URLs near the hero section.
- **WhatsApp:** update the `wa.me/918778970040` links if your number changes.

The WhatsApp button is fixed to the bottom-right corner and remains available while scrolling. The certification row supports swipe gestures on touchscreens and previous/next controls on desktop.
